How it works仕組み

Swaps run on QomSwap (router 0xc1f9…4f30) on QL1 (chain ID 766) through your MetaMask. Approvals are always for the exact swap amount, never unlimited.スワップは QL1（チェーンID 766）の QomSwap（ルーター 0xc1f9…4f30）で、MetaMask から実行します。承認（approve）は毎回スワップする額ちょうどだけにし、無制限の承認はしません。

Native QOM swaps go through WQOM inside the same transaction. Picking QOM → WQOM wraps, and WQOM → QOM unwraps — no pool involved.ネイティブ QOM の交換は、同じトランザクションの中で WQOM 経由で行われます。QOM → WQOM はラップ、WQOM → QOM はアンラップで、プールは使いません。

Quotes compare the direct pool and routes via WQOM / qUSDT / qUSDC / QSWAP / qCAW, all read live with getAmountsOut, and the best one is used.見積もりは、直接プールと WQOM／qUSDT／qUSDC／QSWAP／qCAW 経由のルートをすべてライブで読み比べ（getAmountsOut）、一番良いものを使います。

Which tokens are listed載っているトークン

The list is rebuilt from QomSwap's factory on every load: a token appears when it has a live pool whose QOM side holds at least 10,000,000 QOM, or a qUSDT / qUSDC / qDAI pool. Tokens without a real pool are never listed — for example ZAP has no QomSwap pool on QL1, so it does not appear. If a route quotes zero for your amount, swapping stays disabled.一覧は開くたびに QomSwap のファクトリーから作り直します。プールの QOM 側に 1,000 万 QOM 以上入っているトークン、または qUSDT／qUSDC／qDAI のプールがあるトークンだけを載せます。本物のプールが無いトークンは載せません（例：QL1 の ZAP には QomSwap のプールが無いので、出てきません）。あなたの額で見積もりがゼロになるルートでは、スワップは押せません。
